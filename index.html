  1. Foundations and Transformers 01–02 What an LLM actually does - next-token prediction, tokens, the context window - and how attention works inside it.
  2. Embeddings, Vector Databases and RAG 03–05 Turn text into vectors, search them fast, and ground an LLM in your own data. RAG is the most-asked interview topic.
  3. Agentic AI, MCP and Memory 06–08 When an LLM stops talking and starts doing: the agent loop, tools, the protocol that connects them, and what an agent remembers.
  4. LangChain, LangGraph and Multi-Agent Systems 09–11 The frameworks interviewers ask about, and when several agents beat one.
  5. Production, Guardrails, Evals and LLMOps 12–15 Running it for real users: latency and cost, safety checks, how to measure quality, and how to watch it in production.
  6. Interview Questions Practice The GenAI question bank, the Python & AI/ML question bank, and one drill page per technology (FastAPI, WebSockets, LangChain, RAG, MCP).
  7. Scenario Design Studio System design Practise the system-design round on realistic cases: RAG assistants, support agents, text-to-SQL, latency, security and evaluation.
