🧭Start here — recommended reading order

New to this? Read in this order — each step builds on the one before. Every link opens the right page; use the sidebar to jump between sections anytime.

  1. Global Study Plan Start hereChoose the right route, understand the hours required for every section, and avoid duplicate study across overlapping material.
  2. Foundations of LLMs Module 01 What an LLM actually is — next-token prediction, tokens, the context window. Everything else assumes this.
  3. Memory in LLMs Deep Dive Why the model is stateless and how the context window works — the mental model behind chat history, RAG and agents.
  4. Embeddings & Vector Databases Modules 04–05 Turning text into vectors and searching them fast — the machinery under both RAG and long-term memory.
  5. RAG, End-to-End Module 06 · the only RAG page Everything about RAG in one place and in order: ground an LLM in your own data (chunk → embed → retrieve → augment → generate), then chunking strategies, hybrid retrieval, reranking and evaluation.
  6. Understanding AI Agents Course When an LLM stops just talking and starts doing. Build one support-ticket triage agent from a forty-line loop up to approval gates, guardrails, evaluation and tracing.
  7. How a Claude Agent Works Deep Dive The agent loop made concrete on Claude — tools, the tool runner, the Agent SDK, context & safety.
  8. Agent Protocols — MCP · A2A · A2UI Deep Dive An agent's three boundaries and the open standard at each: MCP for tools and data, A2A for agent-to-agent delegation, A2UI for agent-generated interfaces.
  9. Guardrails Deep Dive The rules an answer must pass before it ships — scope, safety, no leaking secrets or PII, no hallucination.
  10. LLM Evals Deep Dive Prove an LLM app actually works: why vibe testing fails, evaluation methods, golden datasets, and RAG/agent/safety/operational evals — interview-focused.
  11. LLMOps Deep Dive Take an LLM app from demo to production: versioning, experiment tracking, observability, cost/latency and the operating loop — interview-focused.
  12. Langfuse — Observability Deep Dive Once it's running, how you debug and measure it: traces, cost, latency and quality scores.
  13. LangGraph & its components Deep Dive Build agents as stateful graphs — state, nodes, edges, the checkpointer and human-in-the-loop. The structure behind a real agent.
  14. Hermes — open local models Deep Dive · optional Run a capable, free, private agent brain on your own hardware — open function-calling models via Ollama.
  15. Frameworks & Production Modules 08–15 LangChain, LlamaIndex, LangGraph, multi-agent systems and shipping it for real.
  16. Interview Questions One section · three banks Once the concepts are in place, this is the single place to prepare: the GenAI question bank, the Python & AI/ML question bank, and one drill page per technology (FastAPI, WebSockets, LangChain, RAG, MCP).
  17. Scenario Design Studio System design Practise agents, RAG, latency, load, security, prompt injection, SQL safety and evaluation through realistic architecture cases.
