Understanding AI Agents

A hands-on, interview-focused course. You build one support-ticket triage agent and grow it, one capability per lesson, from a forty-line loop into a system with retrieval, memory, approval gates, guardrails, evaluation and tracing. No framework, and no API key.

15 lessons · ~49 h Beginner → intermediate One project throughout Runs offline
✅
All 15 lessons are complete

Roughly 49 hours — about 1 h per weekday for 6–7 weeks, or 4 weeks with longer weekend sessions. Every lesson ships runnable code: 190 passing tests, an evaluation suite of 13 cases, an adversarial corpus of 10 attacks, and six milestone entry points you can restart from. Nothing needs an API key.

Work through them in order. Each lesson adds exactly one capability to the same agent, then deliberately breaks it.

At the heart of every lesson is one idea: an agent runs a loop. It perceives the situation, reasons about what to do, acts by calling a tool, then observes the result — and loops again until the job is done, or until a step limit stops it.

Perceiveread the input / current state
Reasonthe LLM decides what to do next
Act (tool)call a function / run code
Observeread the tool result… then loop

The 15 lessons

Lesson 01

LLM mechanics

Concept + build · ~2.5 h

Messages and roles, the context window, determinism, structured output, what tool calling really is. Builds the model abstraction the whole course runs on.
Lesson 02

The agent loop

Build · ~3 h

Forty lines, no framework. Prompt vs chain vs workflow vs agent, when not to build one, termination and step limits. Adds search_kb.
Lesson 03

Tools & validation

Build · ~3.5 h

Schemas, typed arguments, unknown tools, parallel vs sequential, and the trusted/untrusted boundary. Adds read_ticket, lookup_order.
Lesson 04

Reasoning patterns

Build · ~3 h

ReAct, plan-and-execute, reflection and routing on the same ticket, so the cost is measured rather than argued. Adds draft_reply.
Lesson 05

Retrieval as a tool

Build · ~3.5 h

Chunking, BM25, reranking and a relevance floor — so retrieval can return nothing and the agent can escalate instead of inventing.
Lesson 06

Context & memory

Build · ~2.5 h

Seven stores named, two built. Token budgets, capping a result at the source, compaction that refuses when it would not help. State is not memory.
Lesson 07

Reliability

Build · ~3.5 h

Loop detection, oscillation, timeouts, retry budgets and partial failure. Break it five ways and watch each control catch it. Adds escalate.
Lesson 08

Irreversible actions

Build · ~4 h

Policy in code, derived idempotency keys, approval tokens bound to an amount, append-only audit. Adds issue_refund — the centrepiece.
Lesson 09

Security & guardrails

Build · ~3.5 h

Direct and indirect injection, retrieval poisoning, argument-level authorisation — proved by a test that disables the keyword screen.
Lesson 10

Agent evaluation

Build · ~3 h

Outcome vs trajectory, a golden set where happy paths are the minority, and a regression drill that found a real hole in the suite.
Lesson 11

Tracing, latency & cost

Build · ~3 h

Spans, correlation ids and token accounting — including why agent cost is quadratic in steps, not linear.
Lesson 12

MCP & the tool boundary

Build · ~2.5 h

Host, client, server over JSON-RPC. Exposes the read-only tools and deliberately withholds the one that moves money.
Lesson 13

Multi-agent & A2A

Build · ~4 h

A supervisor measured against the single agent — it loses. Plus a hands-on A2A demo: Agent Cards, task lifecycle, artifacts.
Lesson 14

Deployment & operations

Build · ~3.5 h

A framework comparison you can now judge, then durable runs, resume that restores rather than replays, and prompt versioning.
Lesson 15

Interview capstone

Drills · ~4 h

The deliverables pack, a 15-minute coding round, a 2-minute whiteboard, a system-design exercise and an incident walkthrough.
