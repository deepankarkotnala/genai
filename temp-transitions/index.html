🧭Start here — recommended reading order

New to this? Read in this order — each step builds on the one before. Every link opens the right page; use the sidebar to jump between sections anytime.

  1. Global Study Plan Start hereChoose the right route, understand the hours required for every section, and avoid duplicate study across overlapping material.
  2. Foundations of LLMs Module 01 What an LLM actually is — next-token prediction, tokens, the context window. Everything else assumes this.
  3. Memory in LLMs Deep Dive Why the model is stateless and how the context window works — the mental model behind chat history, RAG and agents.
  4. Embeddings & Vector Databases Modules 04–05 Turning text into vectors and searching them fast — the machinery under both RAG and long-term memory.
  5. RAG Basics Module 06 Ground an LLM in your own data: chunk → embed → retrieve → augment → generate.
  6. RAG, End-to-End Deep Dive The full production pipeline — chunking strategies, hybrid retrieval, reranking, evaluation. The panoramic view.
  7. Understanding AI Agents Course When an LLM stops just talking and starts doing — the agent loop, tools and orchestration.
  8. ATS Agent Build Lab Applied course See six bounded production agents in a real recruitment app: architecture, Python, safety, optimization and evaluation.
  9. GenAI Interview Question Bank Career prep High-signal, topic-wise questions with concise answers, trade-offs and likely follow-ups for modern India GenAI roles.
  10. Complete GenAI Interview Hub 55-page synchronized section The full interview-first site: core track, 173+ Q&A, projects, worked system designs, mock interviews and revision plans — restyled inside this hub.
  11. Scenario Design Studio System design Practise agents, RAG, latency, load, security, prompt injection, SQL safety and evaluation through realistic architecture cases.
  12. How a Claude Agent Works Deep Dive The agent loop made concrete on Claude — tools, the tool runner, the Agent SDK, context & safety.
  13. RAG · MCP · Agents · LLMs Guide A hands-on, build-it guide that ties LLMs, RAG, agents and MCP together with runnable projects.
  14. Agent Protocols — MCP · A2A · A2UI Deep Dive An agent's three boundaries and the open standard at each: MCP for tools and data, A2A for agent-to-agent delegation, A2UI for agent-generated interfaces.
  15. Guardrails Deep Dive The rules an answer must pass before it ships — scope, safety, no leaking secrets or PII, no hallucination.
  16. LLM Evals Deep Dive Prove an LLM app actually works: why vibe testing fails, evaluation methods, golden datasets, and RAG/agent/safety/operational evals — interview-focused.
  17. LLMOps Deep Dive Take an LLM app from demo to production: versioning, experiment tracking, observability, cost/latency and the operating loop — interview-focused.
  18. Langfuse — Observability Deep Dive Once it's running, how you debug and measure it: traces, cost, latency and quality scores.
  19. LangGraph & its components Deep Dive Build agents as stateful graphs — state, nodes, edges, the checkpointer and human-in-the-loop. The structure behind a real agent.
  20. Hermes — open local models Deep Dive · optional Run a capable, free, private agent brain on your own hardware — open function-calling models via Ollama.
  21. Advanced & Production Modules 07–15 Advanced RAG, LangChain, LlamaIndex, multi-agent systems and shipping it for real.
