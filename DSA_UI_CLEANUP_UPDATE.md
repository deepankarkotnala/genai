# DSA UI cleanup

- Removed the green gradient from the DSA contents hero card. It now uses the same neutral elevated surface as the other content cards.
- Replaced the stacked DSA breadcrumb bar and workspace ribbon with one compact top row containing Home, Learn, Practice, Interview, and Progress.
- In focus mode, that compact workspace row remains at the very top; the sidebar and right rail disappear without leaving a blank strip above the lesson.
- Kept the focus exit and theme controls inside the same row instead of floating a separate control over the page.
- Expanded the DSA reading canvas for widescreen displays. Cards and diagrams use the available width while direct prose remains limited to a comfortable line length.
- Removed the low-value right-hand contents rail from the DSA curriculum index so its chapter cards can span the main workspace.
- Preserved responsive behavior: the compact workspace links stay usable on narrow screens, and page padding scales down cleanly.
