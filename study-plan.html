Your minimum study commitment

Target 2–4 focused hours each weekday and 8 focused hours across the weekend. That produces roughly 18–28 hours per week. At that pace, the recommended interview route takes approximately 12–26 weeks. A beginner should expect some topics—especially Transformers, the later half of RAG, LangGraph and production projects—to need a second pass.

Why the full-library total is much larger

The raw total is approximately 460–740 hours across the GenAI sections, plus the optional DSA track. Every topic now has exactly one home, so you can add the rows up: nothing below is a second telling of something above. The one judgement call left is DSA — include it only if your target role screens for it.

Recommended AI Engineer interview route

1

Neural foundations

50–75 hours. Start with Neural Networks for AI Engineers, then complete LLM Foundations, Transformers and Local LLMs.

2

Retrieval and RAG

60–90 hours. Study embeddings, vector databases, then RAG end-to-end — one page, read straight through. Build at least one small retrieval application.

3

Agents, tools and MCP

65–100 hours. Learn the agent loop, tool calling, MCP, LangChain, LlamaIndex, LangGraph and multi-agent trade-offs.

4

Production and projects

80–125 hours. Cover evaluation, observability, security, latency and cost. Complete one project you can defend deeply.

5

Interview conversion

45–70 hours. Work through the Interview Questions section and the design scenarios aloud, under time limits.

✓

Target outcome

You should be able to explain concepts simply, implement core patterns in Python, debug failure modes and defend architecture trade-offs without relying on memorized wording.

Three rules for using the plan

→

Follow dependencies

Neural networks and LLM foundations come before transformers, RAG and agents.

⌁

One page per topic

Every topic has a single home in this portal. If you feel you are re-reading something, you have wandered off the reading order — go back to it.

⌨

Count active work

Hours count when you code, retrieve from memory, draw systems or answer aloud—not when a page is merely open.
