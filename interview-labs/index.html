Where this sits

Interview preparation is one section with three sub-sections: the GenAI question bank (breadth), the Python & AI/ML question bank (language and applied depth), and these drills (one tool at a time). Start with a question bank; come here when a specific technology needs more than a paragraph.

How to use each drill

Learn

Read the mental model and redraw it without looking.

Implement

Type the code independently; modify one requirement.

Explain

Answer every recall question aloud in under 90 seconds.

Test

Complete the quiz and repair any weak concept.

Mock

Do the hard design exercise with a timer and no AI help.
