1 · Foundations

Three short toolkits — bit, math, matrix. Read the one you're rusty on, then head to §2 Pattern library.

Bit manipulation: the operators and the tricks

Binary lets you compute in parallel across bits. The essentials: & (AND), | (OR), ^ (XOR), ~ (NOT), and shifts << / >>. Two identities do most of the work: x ^ x = 0 (XOR cancels pairs) and n & (n−1) (clears the lowest set bit).

Example — the workhorse bit tricks
bits.py
x = 0b1011                     # 11

print(x & 1)                    # 1   -> lowest bit (odd/even test)
print(x & (x - 1))              # 0b1010 = 10  -> cleared lowest set bit
print(x | (1 << 2))             # 0b1111 = 15  -> set bit 2
print(x & ~(1 << 0))            # 0b1010 = 10  -> unset bit 0
print(5 ^ 3 ^ 5)               # 3   -> the 5s cancel via XOR
Output1 · 10 · 15 · 10 · 3
Common idioms: n & 1 tests the last bit · n >> 1 divides by 2 · 1 << k is 2ᵏ · n & (n−1) == 0 checks a power of two · XOR of a full array isolates an unpaired element.

Math: number properties that collapse the work

Many "math" problems hinge on one property: primes via the Sieve of Eratosthenes, GCD via the Euclidean algorithm, fast exponentiation (square-and-multiply, O(log n)), and digit/factor counting (e.g. trailing zeros = factors of 5). Spotting the property replaces a loop over n with a loop over log n — or a closed form.

Example — GCD and fast power
math_tools.py
def gcd(a, b):
    while b:
        a, b = b, a % b        # Euclid: swap in the remainder
    return a

def fast_pow(x, n):            # x**n in O(log n)
    result = 1
    while n:
        if n & 1:
            result *= x         # bit set ⇒ include this power
        x *= x                 # square the base
        n >>= 1
    return result

print(gcd(24, 36), fast_pow(2, 10))   # 12 1024
Output12 1024

Matrix: index carefully, transform in place

Matrix problems are usually about indexing, not algorithms. Two moves recur: the transpose (swap M[i][j] with M[j][i]), which combined with a row reversal rotates 90°; and the boundary walk for spirals. In-place tricks — reusing the first row/column as flags — keep space at O(1).

⚠️
Bit / math / matrix pitfalls

In Python, integers are unbounded — emulating fixed-width signed arithmetic (Sum of Two Integers) needs a 32-bit mask. Watch operator precedence: bitwise operators bind looser than comparisons, so parenthesise ((n & 1) == 0). For slopes, use reduced integer fractions, never floats. In matrices, mind row-vs-column bounds and the overlap at cell (0,0) when using it as a flag.

1 LC 136Single Number Easy XOR cancels pairs

Problem. Every element appears twice except one. Find the single one, in O(n) time and O(1) space. LeetCode 136 ↗

Clarify: Exactly one element is unpaired? (Yes.) No extra memory? (Yes.)

Hint 1
XOR of a number with itself is 0, and XOR with 0 leaves it unchanged.
Hint 2
XOR the whole array; the pairs vanish and the loner remains.

How to think about it The signature bit trick: XOR is associative and commutative, and x ^ x = 0. XOR every element together and all the duplicated pairs cancel to zero, leaving exactly the unique number. One accumulator, no hash set.

single_number.py
from typing import List

class Solution:
    def singleNumber(self, nums):
        result = 0
        for n in nums:
            result ^= n           # pairs cancel; the loner survives
        return result

Time O(n) · Space O(1). XOR-cancels-pairs is the most reused bit identity — Missing Number and Single Number III build on it.

2 LC 191Number of 1 Bits Easy Brian Kernighan · clear the low bit

Problem. Return the number of set bits (the Hamming weight) in an integer. LeetCode 191 ↗

Clarify: Count the 1s in the binary representation? (Yes.)

Hint 1
n & (n−1) removes the lowest set bit.
Hint 2
Count how many times you can do that before n becomes 0.

How to think about it Brian Kernighan's trick: n & (n−1) flips off the lowest set bit. Repeat until n is zero, counting the iterations — you do exactly as many as there are set bits, so it's faster than checking all 32 positions.

number_of_bits.py
class Solution:
    def hammingWeight(self, n):
        count = 0
        while n:
            n &= n - 1            # clears the lowest set bit each step
            count += 1
        return count

Time O(set bits) · Space O(1). Clearing the lowest set bit with n & (n−1) recurs in Hamming distance and power-of-two checks.

3 LC 338Counting Bits Easy DP on bits · halve and add

Problem. For every number from 0 to n, return the count of set bits. LeetCode 338 ↗

Clarify: Return an array of length n+1? (Yes.) Better than O(n·32)? (Yes — O(n).)

Hint 1
bits(i) relates to bits(i >> 1): dropping the last bit halves the number.
Hint 2
bits(i) = bits(i // 2) + (i & 1).

How to think about it A tiny DP over bit counts. Right-shifting i by one drops its lowest bit, so bits(i) = bits(i >> 1) + (i & 1) — the count for a number already computed, plus its final bit. Build the array left to right in O(n).

counting_bits.py
from typing import List

class Solution:
    def countBits(self, n):
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i >> 1] + (i & 1)   # bits(i) = bits(i//2) + last bit
        return dp

Time O(n) · Space O(n). Relating a value's bit count to a smaller, already-solved value is DP meeting bit manipulation.

4 LC 268Missing Number Easy Sum formula (or XOR)

Problem. An array holds n distinct numbers from the range 0..n with one missing. Find it. LeetCode 268 ↗

Clarify: Range is 0..n with exactly one gap? (Yes.)

Hint 1
The full range 0..n sums to n(n+1)/2.
Hint 2
Subtract the actual array sum to reveal the missing number (XOR also works).

How to think about it The numbers 0..n have a known total n(n+1)/2. Subtract the actual array sum and the difference is the missing value. (An XOR of all indices and values also isolates the missing number, overflow-free.)

missing_number.py
from typing import List

class Solution:
    def missingNumber(self, nums):
        n = len(nums)
        return n * (n + 1) // 2 - sum(nums)   # expected total minus actual

Time O(n) · Space O(1). Expected-minus-actual is a clean math shortcut; the XOR variant avoids large sums.

5 LC 231Power of Two Easy Exactly one set bit

Problem. Return whether an integer is a power of two. LeetCode 231 ↗

Clarify: Must be positive? (Yes — powers of two are ≥ 1.)

Hint 1
A power of two has exactly one bit set.
Hint 2
n & (n−1) == 0 tests that (for positive n).

How to think about it A power of two in binary is a single 1 followed by zeros, so n & (n−1) — which clears the lowest set bit — becomes 0 exactly when there was only one bit. Guard n > 0 to reject zero and negatives.

power_of_two.py
class Solution:
    def isPowerOfTwo(self, n):
        return n > 0 and (n & (n - 1)) == 0   # exactly one set bit

Time O(1) · Space O(1). The single-set-bit test is a constant-time classic (Power of Four adds a position check).

6 LC 461Hamming Distance Easy XOR then count bits

Problem. Return the number of positions at which the bits of two integers differ. LeetCode 461 ↗

Clarify: Count differing bit positions? (Yes.)

Hint 1
x ^ y has a 1 exactly where the bits differ.
Hint 2
Count the set bits of the XOR.

How to think about it XOR the two numbers: the result has a 1 in every position where they disagree. Then count those set bits with the clear-the-lowest-bit loop. Two well-known tricks composed.

hamming_distance.py
class Solution:
    def hammingDistance(self, x, y):
        xor = x ^ y
        count = 0
        while xor:
            xor &= xor - 1
            count += 1
        return count

Time O(set bits) · Space O(1). XOR-to-find-differences then popcount composes into Total Hamming Distance later.

7 LC 66Plus One Easy Carry from the last digit

Problem. A number is given as a digit array. Add one and return the resulting digits. LeetCode 66 ↗

Clarify: Digits are most-significant first? (Yes.) Handle the all-nines carry? (Yes.)

Hint 1
Add from the last digit; a digit below 9 just increments and you're done.
Hint 2
A 9 becomes 0 and carries left; all nines prepend a 1.

How to think about it Walk from the least-significant digit. If it's below 9, increment and return immediately. If it's 9, set it to 0 and carry into the next digit. If every digit was 9, the loop finishes and you prepend a leading 1.

plus_one.py
from typing import List

class Solution:
    def plusOne(self, digits):
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits
            digits[i] = 0         # carry ripples left
        return [1] + digits       # all nines ⇒ new leading 1

Time O(n) · Space O(1). Digit-array arithmetic with carry propagation — the basis of big-integer addition.

8 LC 9Palindrome Number Easy Compare digits symmetrically

Problem. Return whether an integer reads the same forwards and backwards. LeetCode 9 ↗

Clarify: Negative numbers are never palindromes? (Yes — the minus sign.)

Hint 1
Negatives fail immediately.
Hint 2
Compare the string to its reverse (or reverse half the number to avoid strings).

How to think about it Negatives can't be palindromes because of the leading sign. For the rest, comparing the string form to its reverse is the simplest correct check. (An integer-only approach reverses just the lower half and compares, avoiding string conversion.)

palindrome_number.py
class Solution:
    def isPalindrome(self, x):
        if x < 0:
            return False
        s = str(x)
        return s == s[::-1]

Time O(digits) · Space O(digits). A gentle number-property problem; the half-reversal variant is the O(1)-space upgrade.

9 LC 171Excel Sheet Column Number Easy Base-26 with A=1

Problem. Convert an Excel column title (A, B, …, Z, AA, …) to its column number. LeetCode 171 ↗

Clarify: A=1, Z=26, AA=27? (Yes.) It's base-26 but 1-indexed? (Yes.)

Hint 1
It's bijective base-26 where A maps to 1, not 0.
Hint 2
result = result*26 + (letter − 'A' + 1) for each character.

How to think about it Treat the title as a base-26 number where A=1 … Z=26. Scan left to right, and for each letter update result = result·26 + value(letter) — the same Horner's-method evaluation as reading a decimal string.

excel_column.py
class Solution:
    def titleToNumber(self, columnTitle):
        result = 0
        for ch in columnTitle:    # base-26, 'A'=1
            result = result * 26 + (ord(ch) - 64)
        return result

Time O(n) · Space O(1). Positional numeral systems (here bijective base-26) are a recurring math-encoding motif.

10 LC 137Single Number II Medium Bit state machine · mod 3

Problem. Every element appears three times except one. Find the single one in O(1) space. LeetCode 137 ↗

Clarify: All but one appear exactly three times? (Yes.) Constant extra space? (Yes.)

Hint 1
Plain XOR fails because triples don't cancel.
Hint 2
Track each bit's count mod 3 using two accumulators, 'ones' and 'twos'.

How to think about it Since triples don't cancel under XOR, count each bit position modulo 3 with two bitmasks. ones holds bits that have appeared once (mod 3), twos those seen twice; the update ones = (ones ^ n) & ~twos then twos = (twos ^ n) & ~ones cycles each bit 0→1→2→0. After processing, ones is the unique number.

single_number_ii.py
from typing import List

class Solution:
    def singleNumber(self, nums):
        ones = twos = 0
        for n in nums:            # bit-state machine counting mod 3
            ones = (ones ^ n) & ~twos
            twos = (twos ^ n) & ~ones
        return ones

Time O(n) · Space O(1). A two-variable bit state machine generalises XOR to 'appears k times' problems.

11 LC 260Single Number III Medium XOR then split by a differing bit

Problem. Exactly two elements appear once (all others twice). Return the two singles. LeetCode 260 ↗

Clarify: Two distinct loners, rest paired? (Yes.) Any order accepted? (Yes.)

Hint 1
XOR everything to get a ^ b (the two unique numbers combined).
Hint 2
A set bit in that XOR differs between a and b — partition the array by it and XOR each half.

How to think about it XOR the whole array to get a ^ b. Any set bit there marks a position where a and b differ; isolate the lowest such bit with xor & (-xor). Partition the numbers by that bit and XOR each group separately — each group cancels its pairs and yields one of the loners.

single_number_iii.py
from typing import List

class Solution:
    def singleNumber(self, nums):
        xor = 0
        for n in nums:
            xor ^= n              # xor = a ^ b (the two loners)
        diff = xor & (-xor)       # a bit where a and b differ
        a = b = 0
        for n in nums:
            if n & diff:
                a ^= n
            else:
                b ^= n
        return [a, b]

Time O(n) · Space O(1). Using a distinguishing bit to split into two Single-Number subproblems is an elegant XOR extension.

12 LC 371Sum of Two Integers Medium Add with XOR and carry

Problem. Compute a + b without using the + or − operators. LeetCode 371 ↗

Clarify: No arithmetic operators, bitwise only? (Yes.) Handle negatives (32-bit)? (Yes.)

Hint 1
XOR adds bits without carrying; AND then left-shift produces the carry.
Hint 2
Loop until there's no carry; mask to 32 bits to emulate signed overflow.

How to think about it Binary addition splits into a carry-free sum (a ^ b) and the carries ((a & b) << 1); repeat until no carry remains. Python's unbounded integers require masking to 32 bits each step, and reinterpreting a result above 0x7FFFFFFF as a negative number via two's complement.

sum_two_integers.py
class Solution:
    def getSum(self, a, b):
        mask = 0xFFFFFFFF
        while b != 0:
            carry = (a & b) << 1
            a = (a ^ b) & mask    # sum without carry
            b = carry & mask
        return a if a <= 0x7FFFFFFF else ~(a ^ mask)   # handle 32-bit negatives

Time O(1) · Space O(1). Emulating fixed-width signed arithmetic with a 32-bit mask is the Python-specific wrinkle here.

13 LC 190Reverse Bits Medium Peel low bit, push high

Problem. Reverse the bits of a 32-bit unsigned integer. LeetCode 190 ↗

Clarify: Exactly 32 bits, including leading zeros? (Yes.)

Hint 1
Build the result bit by bit: shift it left, then OR in the current lowest bit of n.
Hint 2
Do this 32 times as you shift n right.

How to think about it Construct the reversed number one bit at a time. Each of 32 iterations shifts the result left (making room) and ORs in n's current lowest bit, then shifts n right. After 32 steps the bit order is fully mirrored.

reverse_bits.py
class Solution:
    def reverseBits(self, n):
        result = 0
        for _ in range(32):
            result = (result << 1) | (n & 1)   # peel low bit, push high
            n >>= 1
        return result

Time O(1) · Space O(1). Peeling the low bit while pushing into a growing result is a fundamental bit-assembly loop.

14 LC 201Bitwise AND of Numbers Range Medium Common binary prefix

Problem. Return the bitwise AND of all integers in the inclusive range [left, right]. LeetCode 201 ↗

Clarify: AND every number from left to right inclusive? (Yes.)

Hint 1
Any bit that changes within the range becomes 0 in the AND.
Hint 2
The result is the common high-order prefix of left and right.

How to think about it Within a range, every low-order bit that flips somewhere ANDs to 0, so only the shared high-order prefix of left and right survives. Right-shift both until they're equal (counting the shifts), then shift the common value back left to restore the prefix.

range_bitwise_and.py
class Solution:
    def rangeBitwiseAnd(self, left, right):
        shift = 0
        while left < right:       # drop differing low bits ⇒ common prefix
            left >>= 1
            right >>= 1
            shift += 1
        return left << shift

Time O(log n) · Space O(1). Reducing a range-AND to a common-prefix search is the key insight.

15 LC 78Subsets Medium Bitmask enumeration

Problem. Return all possible subsets (the power set) of a set of distinct integers. LeetCode 78 ↗

Clarify: Elements are distinct? (Yes.) Any order of subsets accepted? (Yes.)

Hint 1
There are 2ⁿ subsets — one per bitmask from 0 to 2ⁿ−1.
Hint 2
Bit i of the mask decides whether element i is included.

How to think about it Enumerate the power set with bitmasks: each integer from 0 to 2ⁿ−1 encodes one subset, where bit i means 'include element i'. Loop over all masks and collect the chosen elements. (A backtracking recursion produces the same set.)

subsets.py
from typing import List

class Solution:
    def subsets(self, nums):
        n = len(nums)
        res = []
        for mask in range(1 << n):          # each bitmask = one subset
            res.append([nums[i] for i in range(n) if mask & (1 << i)])
        return res

Time O(n·2ⁿ) · Space O(1) extra. Mapping subsets to bitmasks is the bridge between bit manipulation and combinatorial enumeration.

16 LC 204Count Primes Medium Sieve of Eratosthenes

Problem. Count the prime numbers strictly less than n. LeetCode 204 ↗

Clarify: Strictly less than n? (Yes.) Efficient for large n? (Yes — near-linear.)

Hint 1
Mark non-primes by crossing out multiples of each prime.
Hint 2
Start crossing out at i·i, and only sieve up to √n.

How to think about it The Sieve of Eratosthenes. Assume all numbers are prime, then for each prime i cross out its multiples starting at i·i (smaller multiples were already handled by smaller primes). Sieving only up to √n suffices; the count of remaining true entries is the answer.

count_primes.py
class Solution:
    def countPrimes(self, n):
        if n < 3:
            return 0
        sieve = [True] * n
        sieve[0] = sieve[1] = False
        for i in range(2, int(n ** 0.5) + 1):
            if sieve[i]:
                for j in range(i * i, n, i):   # cross out multiples
                    sieve[j] = False
        return sum(sieve)

Time O(n log log n) · Space O(n). The sieve is the go-to for 'primes up to n' — starting at i·i is the standard optimisation.

17 LC 50Pow(x, n) Medium Binary (fast) exponentiation

Problem. Compute x raised to the power n (n may be negative), efficiently. LeetCode 50 ↗

Clarify: n can be negative? (Yes — invert x and negate n.) Floating result? (Yes.)

Hint 1
Naive multiplication is O(n); squaring is O(log n).
Hint 2
Square x each step and multiply into the result when the current bit of n is 1.

How to think about it Binary exponentiation (square-and-multiply). Read n bit by bit: square x at each step, and whenever the current bit is 1, fold x into the result. This computes xⁿ in O(log n) multiplications. Negative n flips to 1/x with n negated.

pow.py
class Solution:
    def myPow(self, x, n):
        if n < 0:
            x, n = 1 / x, -n
        result = 1.0
        while n:                  # square-and-multiply (binary exponentiation)
            if n & 1:
                result *= x
            x *= x
            n >>= 1
        return result

Time O(log n) · Space O(1). Fast exponentiation also powers modular-pow and matrix-power (e.g. Fibonacci in log n).

18 LC 202Happy Number Medium Cycle detection via a seen-set

Problem. Repeatedly replace a number by the sum of the squares of its digits; return whether it reaches 1. LeetCode 202 ↗

Clarify: Unhappy numbers loop forever in a cycle? (Yes.)

Hint 1
Either you reach 1 (happy) or you revisit a number (a cycle ⇒ unhappy).
Hint 2
Track seen numbers in a set, or use Floyd's cycle detection.

How to think about it Iterate the digit-square-sum transformation. The sequence either hits 1 (happy) or enters a cycle. Detect the cycle with a seen set: if a value repeats before reaching 1, it's unhappy. (Floyd's tortoise-and-hare gives O(1) space.)

happy_number.py
class Solution:
    def isHappy(self, n):
        seen = set()
        while n != 1 and n not in seen:      # a repeat means a non-1 cycle
            seen.add(n)
            n = sum(int(d) ** 2 for d in str(n))
        return n == 1

Time O(log n) per step · Space O(log n). A number-theory problem that's really cycle detection in disguise.

19 LC 172Factorial Trailing Zeroes Medium Count factors of 5

Problem. Return the number of trailing zeroes in n! (n factorial). LeetCode 172 ↗

Clarify: Trailing zeroes come from factors of 10 = 2×5? (Yes — and 5s are the bottleneck.)

Hint 1
Each trailing zero needs a factor of 10 = 2·5; 2s are plentiful, so count the 5s.
Hint 2
Add n//5 + n//25 + n//125 + …

How to think about it Trailing zeros come from factors of 10, i.e. paired 2s and 5s; since 2s vastly outnumber 5s, just count the 5s in n!. That's n//5 + n//25 + n//125 + … — each term adds the numbers contributing an extra factor of 5. Loop dividing n by 5.

trailing_zeroes.py
class Solution:
    def trailingZeroes(self, n):
        count = 0
        while n:                  # count factors of 5 in n!
            n //= 5
            count += n
        return count

Time O(log n) · Space O(1). Reducing a huge factorial to 'how many factors of 5' is a classic number-theory reframing.

20 LC 48Rotate Image Medium Transpose then reverse rows

Problem. Rotate an n×n matrix 90° clockwise, in place. LeetCode 48 ↗

Clarify: In place (no extra matrix)? (Yes.) Clockwise? (Yes.)

Hint 1
A 90° clockwise rotation = transpose, then reverse each row.
Hint 2
Transpose swaps matrix[i][j] with matrix[j][i].

How to think about it Decompose the rotation into two in-place steps: transpose the matrix (swap matrix[i][j] with matrix[j][i]), then reverse each row. The composition is exactly a 90° clockwise turn, done without allocating a second matrix.

rotate_image.py
from typing import List

class Solution:
    def rotate(self, matrix):
        n = len(matrix)
        for i in range(n):        # transpose
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        for row in matrix:        # reverse each row ⇒ 90° clockwise
            row.reverse()

Time O(n²) · Space O(1). 'Transpose then reverse' is the canonical in-place rotation; reversing columns instead gives counter-clockwise.

21 LC 54Spiral Matrix Medium Four shrinking boundaries

Problem. Return all elements of an m×n matrix in spiral (clockwise, inward) order. LeetCode 54 ↗

Clarify: Start top-left, go clockwise inward? (Yes.) Non-square allowed? (Yes.)

Hint 1
Track four boundaries: top, bottom, left, right.
Hint 2
Traverse top row →, right col ↓, bottom row ←, left col ↑, shrinking each boundary after use.

How to think about it Maintain four boundaries and peel the matrix layer by layer: walk the top row left-to-right (then move top down), the right column top-to-bottom (move right in), the bottom row right-to-left, and the left column bottom-to-top. The top ≤ bottom / left ≤ right guards handle non-square and single-line leftovers.

spiral_matrix.py
from typing import List

class Solution:
    def spiralOrder(self, matrix):
        res = []
        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1
        while top <= bottom and left <= right:
            for j in range(left, right + 1):
                res.append(matrix[top][j])
            top += 1
            for i in range(top, bottom + 1):
                res.append(matrix[i][right])
            right -= 1
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    res.append(matrix[bottom][j])
                bottom -= 1
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    res.append(matrix[i][left])
                left += 1
        return res

Time O(m·n) · Space O(1) extra. Shrinking-boundary traversal is the standard matrix-spiral technique (Spiral Matrix II fills instead of reads).

22 LC 73Set Matrix Zeroes Medium Use row 0 / col 0 as flags

Problem. If a cell is 0, set its entire row and column to 0 — in place, with O(1) extra space. LeetCode 73 ↗

Clarify: In place with constant extra space? (Yes.) Original zeros drive the wipes? (Yes.)

Hint 1
A naive marker array costs O(m+n); instead reuse the first row and column as flags.
Hint 2
Handle the first row/column separately since they store the flags.

How to think about it Use the matrix's own first row and column as the zero-flags. First record separately whether row 0 or column 0 originally contains a zero. Then, for each interior zero, mark its row's flag (in column 0) and column's flag (in row 0). Zero out interior cells whose flag is set, and finally wipe row 0 / column 0 if their recorded flags were set.

set_matrix_zeroes.py
from typing import List

class Solution:
    def setZeroes(self, matrix):
        m, n = len(matrix), len(matrix[0])
        first_row = any(matrix[0][j] == 0 for j in range(n))
        first_col = any(matrix[i][0] == 0 for i in range(m))
        for i in range(1, m):     # use row 0 / col 0 as flags
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = matrix[0][j] = 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        if first_row:
            for j in range(n):
                matrix[0][j] = 0
        if first_col:
            for i in range(m):
                matrix[i][0] = 0

Time O(m·n) · Space O(1). Encoding state inside the input itself is a powerful in-place trick — mind the overlap at cell (0,0).

23 LC 240Search a 2D Matrix II Medium Staircase from a corner

Problem. Search a value in a matrix whose rows and columns are each sorted ascending. LeetCode 240 ↗

Clarify: Both rows and columns sorted ascending? (Yes.)

Hint 1
Start at the top-right (or bottom-left) corner.
Hint 2
There, one direction increases and the other decreases — eliminate a row or column each step.

How to think about it Start at the top-right corner, where moving left strictly decreases values and moving down strictly increases them. Compare with the target: if the cell is larger, drop the column (move left); if smaller, drop the row (move down). Each step eliminates a full row or column, giving O(m+n).

search_2d_matrix.py
from typing import List

class Solution:
    def searchMatrix(self, matrix, target):
        if not matrix:
            return False
        r, c = 0, len(matrix[0]) - 1        # start at top-right corner
        while r < len(matrix) and c >= 0:
            if matrix[r][c] == target:
                return True
            elif matrix[r][c] > target:
                c -= 1            # column too big
            else:
                r += 1            # row too small
        return False

Time O(m+n) · Space O(1). The staircase walk exploits sortedness in both dimensions — far better than a per-row binary search.

24 LC 477Total Hamming Distance Hard Count per bit column

Problem. Return the sum of Hamming distances between every pair of numbers in an array. LeetCode 477 ↗

Clarify: Sum over all unordered pairs? (Yes.) Values fit in 32 bits? (Yes.)

Hint 1
Pairwise comparison is O(n²) — too slow. Count per bit position instead.
Hint 2
For each bit, if k numbers have it set, they contribute k·(n−k) differing pairs.

How to think about it Avoid the O(n²) pairwise loop by counting contributions per bit. For each of the 32 bit positions, if k numbers have that bit set and n−k don't, every set/unset pairing differs there, contributing k·(n−k). Summing over all bits gives the total in O(32·n).

total_hamming.py
from typing import List

class Solution:
    def totalHammingDistance(self, nums):
        total = 0
        n = len(nums)
        for bit in range(32):     # each bit contributes ones*(zeros) pairs
            ones = sum((num >> bit) & 1 for num in nums)
            total += ones * (n - ones)
        return total

Time O(32·n) · Space O(1). Decomposing a pairwise sum into independent per-bit columns collapses O(n²) to linear.

25 LC 43Multiply Strings Hard Grade-school multiplication

Problem. Multiply two non-negative integers given as strings, without built-in big-integer conversion. LeetCode 43 ↗

Clarify: Numbers can be very large (beyond 64-bit)? (Yes.) No int() shortcut? (Yes.)

Hint 1
The product of an m-digit and n-digit number has at most m+n digits.
Hint 2
num1[i]·num2[j] lands at result positions i+j and i+j+1; accumulate then carry.

How to think about it Simulate long multiplication into an (m+n)-digit buffer. The product of digits at positions i and j contributes to result positions i+j (carry) and i+j+1 (units). Accumulate all products, propagating carries as you go, then strip leading zeros.

multiply_strings.py
class Solution:
    def multiply(self, num1, num2):
        if num1 == "0" or num2 == "0":
            return "0"
        m, n = len(num1), len(num2)
        result = [0] * (m + n)
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                mul = (ord(num1[i]) - 48) * (ord(num2[j]) - 48)
                p1, p2 = i + j, i + j + 1          # positions in the result
                total = mul + result[p2]
                result[p2] = total % 10
                result[p1] += total // 10          # carry
        return "".join(map(str, result)).lstrip("0") or "0"

Time O(m·n) · Space O(m+n). The position rule i+j / i+j+1 is the crux of digit-array multiplication.

26 LC 149Max Points on a Line Hard Slope counting with reduced fractions

Problem. Given points on a plane, return the maximum number that lie on the same straight line. LeetCode 149 ↗

Clarify: Duplicate points? (Assume distinct here.) Vertical lines allowed? (Yes.)

Hint 1
Fix each point and count how many others share each slope through it.
Hint 2
Represent slope as a reduced (dx, dy) fraction with a normalised sign to avoid float error.

How to think about it For each anchor point, bucket every other point by the slope of the line joining them. To compare slopes exactly (no floating error), reduce each (dx, dy) by their GCD and normalise the sign. The largest bucket plus the anchor is the most collinear points through it; take the max over all anchors.

max_points_line.py
from collections import defaultdict
from math import gcd
from typing import List

class Solution:
    def maxPoints(self, points):
        n = len(points)
        if n <= 2:
            return n
        best = 1
        for i in range(n):
            slopes = defaultdict(int)
            for j in range(n):
                if i == j:
                    continue
                dx = points[j][0] - points[i][0]
                dy = points[j][1] - points[i][1]
                g = gcd(dx, dy)
                if g:
                    dx, dy = dx // g, dy // g
                if dx < 0 or (dx == 0 and dy < 0):   # normalise slope sign
                    dx, dy = -dx, -dy
                slopes[(dx, dy)] += 1
                best = max(best, slopes[(dx, dy)] + 1)
        return best

Time O(n²) · Space O(n). Reduced integer fractions as slope keys sidestep the precision traps of floating-point division.

27 LC 60Permutation Sequence Hard Factorial number system

Problem. Return the k-th permutation (1-indexed) of the numbers 1..n in lexical order. LeetCode 60 ↗

Clarify: 1-indexed k? (Yes.) Permutations in increasing order? (Yes.)

Hint 1
Don't enumerate — the first digit is determined by k // (n−1)!.
Hint 2
Peel one digit at a time using factorials of the remaining length.

How to think about it Construct the permutation directly with the factorial number system. Fixing the first element partitions the permutations into blocks of (n−1)!, so k // (n−1)! selects which remaining number leads; take the remainder and repeat for the next position. Each step pops the chosen digit from the pool.

permutation_sequence.py
from math import factorial

class Solution:
    def getPermutation(self, n, k):
        nums = list(range(1, n + 1))
        k -= 1                    # 0-indexed
        result = []
        for i in range(n, 0, -1):
            idx, k = divmod(k, factorial(i - 1))   # which bucket of (i-1)! perms
            result.append(str(nums.pop(idx)))
        return "".join(result)

Time O(n²) · Space O(n). Indexing straight to the k-th permutation via factorials beats generating all k of them.

28 LC 166Fraction to Recurring Decimal Hard Long division + cycle detection

Problem. Given numerator and denominator, return the fraction as a string, wrapping any repeating part in parentheses. LeetCode 166 ↗

Clarify: Detect and parenthesise the repeating block? (Yes.) Handle sign and exact division? (Yes.)

Hint 1
Do long division digit by digit on the remainder.
Hint 2
Remember each remainder's position; if a remainder repeats, the digits since then form the cycle.

How to think about it Perform long division manually. After the integer part, process the fractional digits from the remainder, multiplying by 10 each step. Track every remainder's output position in a map: the first time a remainder recurs, the digits produced since its first appearance are the repeating block, so wrap them in parentheses. Handle sign and exact termination up front.

fraction_decimal.py
class Solution:
    def fractionToDecimal(self, numerator, denominator):
        if numerator == 0:
            return "0"
        res = []
        if (numerator < 0) != (denominator < 0):
            res.append("-")
        numerator, denominator = abs(numerator), abs(denominator)
        res.append(str(numerator // denominator))
        rem = numerator % denominator
        if rem == 0:
            return "".join(res)
        res.append(".")
        seen = {}                 # remainder -> position, to detect the cycle
        while rem != 0:
            if rem in seen:
                res.insert(seen[rem], "(")
                res.append(")")
                break
            seen[rem] = len(res)
            rem *= 10
            res.append(str(rem // denominator))
            rem %= denominator
        return "".join(res)

Time O(period) · Space O(period). A repeated remainder is precisely what signals a repeating decimal — the map turns that into cycle detection.

Concept checks

Why does XOR-ing every element of an array where all numbers appear twice except one leave exactly the unique number?
XOR is commutative and associative and x^x=0, so every duplicated pair cancels to 0, and 0^unique = unique
Because XOR sorts the numbers first
Because XOR keeps only the largest value
Order doesn't matter for XOR, so you can group each value with its duplicate; each pair XORs to 0, and XOR-ing 0 with the lone value leaves it untouched. That's why the trick needs O(1) space and no sorting.
Why does a 90°-clockwise rotation equal 'transpose, then reverse each row'?
Transposing turns rows into columns (reflecting across the main diagonal); reversing each row then flips left-to-right, and the two reflections compose into a 90° rotation
Because transposing already rotates the matrix by itself
Because reversing rows sorts the matrix
A rotation is two reflections. Transpose reflects across the main diagonal; reversing each row reflects across the vertical axis. Composing those two reflections yields a 90° clockwise rotation — and both steps are in place, so no second matrix is needed.
