This chapter covers the big 2D families: grid paths, two-sequence DP (LCS, edit distance), palindrome and interval DP, 2D knapsack, and pattern matching. This chapter builds directly on Chapter 18 — same state/recurrence/order discipline, one more dimension. Read top to bottom. Already fluent? Skip to §2 Pattern library.

When you need a second dimension

You reach for a 2D state when a subproblem needs two indices to describe it: a position in a grid (row, column), a pair of prefixes across two sequences (i in one, j in the other), or the two endpoints of a substring/interval (i..j). The table dp[i][j] stores the answer to each such subproblem, filled so every cell's dependencies are ready before it.

The three big shapes: grid DP (from above / from the left), two-sequence DP (match ⇒ diagonal, else max/min of neighbours), and interval DP (split the range i..j at some k, fill shortest-interval-first).

Grid DP: paths through a matrix

The simplest 2D DP counts paths in a grid: the ways to reach a cell equal the ways from the cell above plus the ways from the cell to the left. Because each cell needs only the row above and the cell to its left, one rolling row suffices.

Example — count paths, full table then one row
unique_paths.py
def unique_paths(m, n):
    dp = [[1] * n for _ in range(m)]        # top row and left column = 1
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]   # from above + from left
    return dp[m - 1][n - 1]

def unique_paths_1row(m, n):                # same result, O(n) space
    dp = [1] * n
    for _ in range(1, m):
        for j in range(1, n):
            dp[j] += dp[j - 1]
    return dp[-1]

print(unique_paths(3, 7), unique_paths_1row(3, 7))   # 28 28
Output28 28

Two-sequence DP: the LCS grid

A huge family compares two strings/arrays with dp[i][j] over their prefixes. The template — matching characters extend the diagonal, mismatches take the best of the two neighbours — solves longest common subsequence, and with small tweaks edit distance, uncrossed lines, interleaving, and distinct subsequences.

Example — longest common subsequence
lcs.py
def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1        # match ⇒ diagonal + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

print(lcs("abcde", "ace"))                  # 3
Output3

The extra row and column of zeros represent an empty prefix — they remove base-case special-casing inside the loop.

Interval DP: fill by increasing length

Some problems are defined over a range s[i..j] and split at an internal point k — palindromes, burst balloons, matrix-chain, polygon triangulation. The key is the fill order: a range depends on strictly shorter ranges, so iterate by increasing interval length (or i downward, j upward).

⚠️
2D DP pitfalls

Get the fill order right — grid DP is row-major, interval DP is by length; filling in the wrong order reads uninitialised cells. Use the extra 0-row/0-column for empty prefixes to avoid off-by-one base cases. For 0/1 knapsack over a capacity, still iterate the capacity downward. And for interval problems like Burst Balloons, fix the last action (not the first) so the subproblems become independent.

1 LC 118Pascal's Triangle Easy Build each row from the one above

Problem. Return the first numRows of Pascal's triangle, where each number is the sum of the two directly above it. LeetCode 118 ↗

Clarify: Row edges are always 1? (Yes.) 1-indexed count of rows? (numRows total rows.)

Hint 1
Each interior entry equals the sum of the two entries above it.
Hint 2
Build row i from row i−1: [1] + pairwise sums + [1].

How to think about it The gentlest 2D DP: each row depends only on the row above. Start with [1]; to build the next row, put 1s on the ends and set each interior value to the sum of the two entries above it. This 'a row from the previous row' shape is the seed of every grid DP that follows.

pascals_triangle.py
from typing import List

class Solution:
    def generate(self, numRows):
        res = [[1]]
        for _ in range(1, numRows):
            prev = res[-1]
            row = [1] + [prev[j] + prev[j + 1] for j in range(len(prev) - 1)] + [1]
            res.append(row)
        return res

Time O(rows²) · Space O(rows²). A row-from-previous-row recurrence — the simplest possible 2D table.

2 LC 62Unique Paths Medium Grid DP · sum of two neighbours

Problem. A robot moves only right or down on an m×n grid. Count the distinct paths from the top-left to the bottom-right. LeetCode 62 ↗

Clarify: Moves are right/down only? (Yes.) Count paths, not list them? (Yes.)

Hint 1
Paths to a cell = paths from the cell above + paths from the cell to the left.
Hint 2
The top row and left column each have exactly one path; one row of DP suffices.

How to think about it The archetypal grid DP: the number of paths to a cell equals paths from above plus paths from the left, since those are the only ways in. Initialise the top row to 1 and sweep, accumulating dp[j] += dp[j−1]. A single rolling row captures the whole 2D table.

unique_paths.py
class Solution:
    def uniquePaths(self, m, n):
        dp = [1] * n                  # top row: one way to each cell
        for _ in range(1, m):
            for j in range(1, n):
                dp[j] += dp[j - 1]    # paths from above + from the left
        return dp[-1]

Time O(m·n) · Space O(n). 'From above + from the left' is the transition behind nearly every grid problem here.

3 LC 63Unique Paths II Medium Grid DP with obstacles

Problem. Same as Unique Paths, but some cells contain obstacles that can't be entered. Count the valid paths. LeetCode 63 ↗

Clarify: An obstacle cell contributes zero paths? (Yes.) Start or end could be blocked? (Yes — then 0.)

Hint 1
An obstacle cell has 0 paths through it — zero out its DP value.
Hint 2
Otherwise use the same from-above + from-left accumulation.

How to think about it Identical to Unique Paths with one rule: an obstacle cell is unreachable, so its DP value is 0 regardless of neighbours. Sweep the grid accumulating dp[j] += dp[j−1] for open cells and forcing dp[j] = 0 at obstacles. A blocked start yields 0 everywhere.

unique_paths_ii.py
from typing import List

class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid):
        m, n = len(obstacleGrid), len(obstacleGrid[0])
        dp = [0] * n
        dp[0] = 1 if obstacleGrid[0][0] == 0 else 0
        for i in range(m):
            for j in range(n):
                if obstacleGrid[i][j] == 1:
                    dp[j] = 0         # blocked cell is unreachable
                elif j > 0:
                    dp[j] += dp[j - 1]
        return dp[-1]

Time O(m·n) · Space O(n). Adding a 'this state is invalid ⇒ zero it' rule is a common DP adaptation.

4 LC 64Minimum Path Sum Medium Grid DP · minimise instead of count

Problem. Find a path from top-left to bottom-right (moving right/down) that minimises the sum of numbers along it. LeetCode 64 ↗

Clarify: Moves right/down only? (Yes.) Minimise the total, not count paths? (Yes.)

Hint 1
dp[cell] = grid value + min(path from above, path from left).
Hint 2
One rolling row works; the first column only inherits from above.

How to think about it Same grid structure, but swap 'count' for 'minimise': the cheapest way into a cell is its own value plus the smaller of the best-into-above and best-into-left. Roll one row; the leftmost cell can only come from above, so it just adds its value to the running row.

min_path_sum.py
from typing import List

class Solution:
    def minPathSum(self, grid):
        m, n = len(grid), len(grid[0])
        dp = [float("inf")] * n
        dp[0] = 0
        for i in range(m):
            for j in range(n):
                if j == 0:
                    dp[j] += grid[i][j]
                else:
                    dp[j] = min(dp[j], dp[j - 1]) + grid[i][j]
        return dp[-1]

Time O(m·n) · Space O(n). Counting and optimising share the same grid transition — swap sum for min.

5 LC 120Triangle Medium Bottom-up over adjacent choices

Problem. Given a triangle of numbers, return the minimum path sum from top to bottom, moving to an adjacent number each step. LeetCode 120 ↗

Clarify: From index j you move to j or j+1 in the next row? (Yes.) Minimise the total? (Yes.)

Hint 1
Working bottom-up avoids edge cases at the triangle's borders.
Hint 2
dp[j] = triangle[i][j] + min(dp[j], dp[j+1]).

How to think about it Process the triangle bottom-up. Start with the last row as the DP array; for each higher row, a cell's best total is its value plus the smaller of the two reachable cells below it (dp[j] and dp[j+1]). Bottom-up keeps every cell's two children in range, avoiding boundary special-cases. The apex holds the answer.

triangle.py
from typing import List

class Solution:
    def minimumTotal(self, triangle):
        dp = triangle[-1][:]          # start from the bottom row
        for i in range(len(triangle) - 2, -1, -1):
            for j in range(len(triangle[i])):
                dp[j] = triangle[i][j] + min(dp[j], dp[j + 1])
        return dp[0]

Time O(n²) · Space O(n). Choosing the sweep direction (here bottom-up) can eliminate boundary handling entirely.

6 LC 931Minimum Falling Path Sum Medium Grid DP · three predecessors

Problem. Return the minimum sum of a falling path through a square matrix, choosing from the three cells above-left, above, above-right each row. LeetCode 931 ↗

Clarify: From (i,j) the next row can be j−1, j, or j+1? (Yes.) Start anywhere in the top row? (Yes.)

Hint 1
Each cell's best comes from the minimum of the three cells above it.
Hint 2
Handle the left/right edges where only two cells are above.

How to think about it A grid DP where each cell draws from up to three predecessors: directly above and the two diagonals. Roll a row: the best total ending at (i, j) is its value plus the minimum of dp[j−1], dp[j], dp[j+1] (clamped at the edges). The answer is the minimum over the final row.

min_falling_path.py
from typing import List

class Solution:
    def minFallingPathSum(self, matrix):
        n = len(matrix)
        dp = matrix[0][:]
        for i in range(1, n):
            new = [0] * n
            for j in range(n):
                best = dp[j]
                if j > 0:
                    best = min(best, dp[j - 1])
                if j < n - 1:
                    best = min(best, dp[j + 1])
                new[j] = matrix[i][j] + best
            dp = new
        return min(dp)

Time O(n²) · Space O(n). Widening the predecessor set from two to three cells is a small, natural extension of grid DP.

7 LC 1143Longest Common Subsequence Medium Two-sequence DP · the template

Problem. Return the length of the longest subsequence common to two strings. LeetCode 1143 ↗

Clarify: Subsequence (order preserved, not contiguous)? (Yes.) Return just the length? (Yes.)

Hint 1
dp[i][j] = LCS of the first i chars of one and first j of the other.
Hint 2
Match ⇒ dp[i−1][j−1]+1; mismatch ⇒ max(dp[i−1][j], dp[i][j−1]).

How to think about it The foundational two-sequence DP. Let dp[i][j] be the LCS length of the prefixes text1[:i] and text2[:j]. If the current characters match, extend the diagonal (dp[i−1][j−1]+1); otherwise take the better of dropping one character from either string. Row 0 and column 0 are zero.

lcs.py
class Solution:
    def longestCommonSubsequence(self, text1, text2):
        m, n = len(text1), len(text2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1   # extend the common run
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]

Time O(m·n) · Space O(m·n). This grid — match ⇒ diagonal, else ⇒ max of neighbours — underlies edit distance, uncrossed lines, and more.

8 LC 583Delete Operation for Two Strings Medium LCS · delete the rest

Problem. Return the minimum number of deletions to make two strings equal (delete a character from either string per step). LeetCode 583 ↗

Clarify: Only deletions allowed? (Yes.) Make the two strings identical? (Yes.)

Hint 1
The characters you keep form the longest common subsequence.
Hint 2
Deletions = (len1 − LCS) + (len2 − LCS).

How to think about it Whatever survives in both strings must be their longest common subsequence. So compute the LCS, then delete everything else: (m − LCS) characters from the first string and (n − LCS) from the second. The LCS sub-problem is exactly the previous problem's grid.

delete_two_strings.py
class Solution:
    def minDistance(self, word1, word2):
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        lcs = dp[m][n]                # delete everything outside the LCS
        return (m - lcs) + (n - lcs)

Time O(m·n) · Space O(m·n). Reframing 'min deletions' as 'keep the LCS' is a clean reduction to a known DP.

9 LC 1035Uncrossed Lines Medium LCS in disguise

Problem. Connect equal values in two rows with straight lines that don't cross; return the maximum number of such lines. LeetCode 1035 ↗

Clarify: Lines connect equal values and mustn't intersect? (Yes.) Each value used once? (Yes.)

Hint 1
Non-crossing connections must preserve order in both arrays.
Hint 2
That's exactly the longest common subsequence of the two arrays.

How to think about it Two connecting lines cross unless the matched values keep the same relative order in both arrays — which is precisely the definition of a common subsequence. So the maximum number of non-crossing lines is the LCS length of the two arrays. Reuse the LCS grid verbatim.

uncrossed_lines.py
from typing import List

class Solution:
    def maxUncrossedLines(self, nums1, nums2):
        m, n = len(nums1), len(nums2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if nums1[i - 1] == nums2[j - 1]:      # uncrossed lines = LCS
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]

Time O(m·n) · Space O(m·n). Recognising a disguised LCS is the whole battle — the code is the template.

10 LC 718Maximum Length of Repeated Subarray Medium LCS variant · must be contiguous

Problem. Return the length of the longest subarray that appears in both arrays. LeetCode 718 ↗

Clarify: Subarray (contiguous), not subsequence? (Yes.) Return the length? (Yes.)

Hint 1
Like LCS, but a mismatch RESETS the run to 0 (contiguity).
Hint 2
dp[i][j] = dp[i−1][j−1] + 1 on a match, else 0; track the global max.

How to think about it A contiguous cousin of LCS. dp[i][j] is the length of the common subarray ending at nums1[i−1] and nums2[j−1]: on a match extend the diagonal, but on a mismatch reset to 0 (a subarray can't skip elements). The answer is the maximum cell, not the corner.

repeated_subarray.py
from typing import List

class Solution:
    def findLength(self, nums1, nums2):
        m, n = len(nums1), len(nums2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        best = 0
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if nums1[i - 1] == nums2[j - 1]:      # must be CONTIGUOUS
                    dp[i][j] = dp[i - 1][j - 1] + 1
                    best = max(best, dp[i][j])
        return best

Time O(m·n) · Space O(m·n). 'Reset on mismatch, track the global max' is what turns subsequence DP into subarray DP.

11 LC 97Interleaving String Medium Two-string boolean grid

Problem. Return whether s3 is formed by interleaving s1 and s2 while preserving each one's character order. LeetCode 97 ↗

Clarify: All of s1 and s2 must be used? (Yes.) Order within each preserved? (Yes.)

Hint 1
dp[i][j] = can s3[:i+j] be formed from s1[:i] and s2[:j]?
Hint 2
Reach (i,j) by taking s1[i−1] (from (i−1,j)) or s2[j−1] (from (i,j−1)) matching s3's next char.

How to think about it Let dp[i][j] mean the first i+j characters of s3 can be built from s1[:i] and s2[:j]. You reach that state either by matching s1[i−1] to s3[i+j−1] (from dp[i−1][j]) or s2[j−1] to it (from dp[i][j−1]). Length mismatch is an instant false.

interleaving_string.py
class Solution:
    def isInterleave(self, s1, s2, s3):
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True
        for i in range(m + 1):
            for j in range(n + 1):
                if i > 0 and s1[i - 1] == s3[i + j - 1]:
                    dp[i][j] = dp[i][j] or dp[i - 1][j]
                if j > 0 and s2[j - 1] == s3[i + j - 1]:
                    dp[i][j] = dp[i][j] or dp[i][j - 1]
        return dp[m][n]

Time O(m·n) · Space O(m·n). A boolean two-string grid where each state is reachable from its top or left neighbour.

12 LC 72Edit Distance Medium Insert / delete / replace

Problem. Return the minimum number of insertions, deletions, or replacements to turn word1 into word2. LeetCode 72 ↗

Clarify: Three operations each cost 1? (Yes.) Transform word1 into word2? (Yes.)

Hint 1
dp[i][j] = edit distance between the first i and first j characters.
Hint 2
Match ⇒ dp[i−1][j−1]; else 1 + min(delete, insert, replace).

How to think about it The classic Levenshtein DP. dp[i][j] is the edit distance between the prefixes. Matching characters cost nothing (dp[i−1][j−1]); otherwise take 1 + the minimum of delete (dp[i−1][j]), insert (dp[i][j−1]), and replace (dp[i−1][j−1]). The base row/column are pure inserts/deletes.

edit_distance.py
class Solution:
    def minDistance(self, word1, word2):
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):
            dp[i][0] = i              # delete all of word1[:i]
        for j in range(n + 1):
            dp[0][j] = j              # insert all of word2[:j]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:                 # delete / insert / replace
                    dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
        return dp[m][n]

Time O(m·n) · Space O(m·n). Edit distance is the two-sequence DP everyone should know cold — three operations, three predecessors.

13 LC 516Longest Palindromic Subsequence Medium Interval DP on one string

Problem. Return the length of the longest palindromic subsequence of a string. LeetCode 516 ↗

Clarify: Subsequence (not contiguous)? (Yes.) Return the length? (Yes.)

Hint 1
dp[i][j] = LPS length within s[i..j].
Hint 2
s[i]==s[j] ⇒ dp[i+1][j−1]+2; else max(dp[i+1][j], dp[i][j−1]).

How to think about it Define dp[i][j] over the substring s[i..j]. If the ends match, they wrap an inner palindrome: dp[i+1][j−1]+2. Otherwise drop one end and take the better. Because states depend on shorter intervals, iterate i downward and j upward. (It's also the LCS of s with its reverse.)

lps.py
class Solution:
    def longestPalindromeSubseq(self, s):
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        return dp[0][n - 1]

Time O(n²) · Space O(n²). Interval DP — a table indexed by substring endpoints, filled shortest-interval-first.

14 LC 5Longest Palindromic Substring Medium Interval DP · contiguous palindrome

Problem. Return the longest contiguous palindromic substring. LeetCode 5 ↗

Clarify: Substring (contiguous)? (Yes.) Any one longest is acceptable? (Yes.)

Hint 1
dp[i][j] = is s[i..j] a palindrome?
Hint 2
True when s[i]==s[j] and the inside s[i+1..j−1] is already a palindrome (or length ≤ 2).

How to think about it Fill a boolean table by increasing length: s[i..j] is a palindrome when its ends match and the interior s[i+1..j−1] is a palindrome (trivially true for lengths 1–2). Track the longest true interval as you go. Iterating by length guarantees the smaller interior is computed first.

longest_palindrome.py
class Solution:
    def longestPalindrome(self, s):
        n = len(s)
        if n < 2:
            return s
        dp = [[False] * n for _ in range(n)]
        start, maxlen = 0, 1
        for i in range(n):
            dp[i][i] = True
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j] and (length == 2 or dp[i + 1][j - 1]):
                    dp[i][j] = True
                    if length > maxlen:
                        start, maxlen = i, length
        return s[start:start + maxlen]

Time O(n²) · Space O(n²). The palindrome interval DP; expand-around-center gives the same O(n²) with O(1) space.

15 LC 647Palindromic Substrings Medium Interval DP · count palindromes

Problem. Count how many palindromic substrings a string contains (different positions count separately). LeetCode 647 ↗

Clarify: Count all substrings that are palindromes, including single characters? (Yes.)

Hint 1
Same palindrome table as the previous problem.
Hint 2
Increment a counter every time dp[i][j] is true.

How to think about it Reuse the palindrome interval table: s[i..j] is a palindrome when the ends match and the interior is one (or the span is ≤ 2). Iterate intervals so the interior is ready, and simply count every interval that turns out to be a palindrome. Each single character contributes one.

palindromic_substrings.py
class Solution:
    def countSubstrings(self, s):
        n = len(s)
        dp = [[False] * n for _ in range(n)]
        count = 0
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j - i < 2 or dp[i + 1][j - 1]):
                    dp[i][j] = True
                    count += 1
        return count

Time O(n²) · Space O(n²). Once you have the palindrome table, counting is a one-line addition.

16 LC 494Target Sum Medium 0/1 knapsack · subset counting

Problem. Assign + or − to each number so the expression equals a target; count the ways. LeetCode 494 ↗

Clarify: Every number gets exactly one sign? (Yes.) Count distinct sign assignments? (Yes.)

Hint 1
Let P be the positive subset, N the negative. P − N = target and P + N = total.
Hint 2
So P = (total + target)/2 — count subsets summing to P (0/1 knapsack).

How to think about it Split the numbers into a positive subset P and a negative subset N. From P − N = target and P + N = total, the positive subset must sum to (total + target)/2. So the answer is the number of subsets hitting that sum — a 0/1 subset-count knapsack with capacity iterated downward.

target_sum.py
from typing import List

class Solution:
    def findTargetSumWays(self, nums, target):
        total = sum(nums)
        # split into positive subset P and negative N: P - N = target, P + N = total
        if (total + target) % 2 != 0 or abs(target) > total:
            return 0
        subset = (total + target) // 2
        dp = [0] * (subset + 1)       # count subsets summing to `subset`
        dp[0] = 1
        for num in nums:
            for a in range(subset, num - 1, -1):
                dp[a] += dp[a - num]
        return dp[subset]

Time O(n·sum) · Space O(sum). Algebra converts a signs problem into a familiar subset-sum count.

17 LC 474Ones and Zeroes Medium Knapsack with two capacities

Problem. Given binary strings and budgets of m zeros and n ones, return the size of the largest subset you can form. LeetCode 474 ↗

Clarify: Two independent capacity limits (zeros and ones)? (Yes.) Maximise the count of strings? (Yes.)

Hint 1
It's 0/1 knapsack, but the 'weight' is two-dimensional: zeros and ones.
Hint 2
dp[i][j] = max strings using ≤ i zeros and ≤ j ones; iterate both capacities downward.

How to think about it A 0/1 knapsack with a two-dimensional capacity. dp[i][j] is the most strings using at most i zeros and j ones. For each string (costing its zero/one counts), update both capacities downward so it's used at most once: dp[i][j] = max(dp[i][j], dp[i−z][j−o]+1).

ones_and_zeroes.py
from typing import List

class Solution:
    def findMaxForm(self, strs, m, n):
        dp = [[0] * (n + 1) for _ in range(m + 1)]   # capacities: m zeros, n ones
        for s in strs:
            zeros = s.count("0")
            ones = len(s) - zeros
            for i in range(m, zeros - 1, -1):        # 0/1 knapsack ⇒ iterate downward
                for j in range(n, ones - 1, -1):
                    dp[i][j] = max(dp[i][j], dp[i - zeros][j - ones] + 1)
        return dp[m][n]

Time O(L·m·n) · Space O(m·n). Knapsack generalises to multiple capacities by adding a table dimension per resource.

18 LC 221Maximal Square Medium Square DP · min of three neighbours

Problem. In a binary matrix, return the area of the largest square of all 1s. LeetCode 221 ↗

Clarify: Square (equal sides), not rectangle? (Yes.) Return the area? (Yes.)

Hint 1
dp[i][j] = side of the largest all-1 square with its bottom-right corner at (i,j).
Hint 2
If the cell is 1: dp = 1 + min(top, left, top-left).

How to think about it Let dp[i][j] be the side length of the largest all-ones square whose bottom-right corner is (i, j). A cell of 1 can extend a square only as far as its three neighbours (top, left, top-left) all allow, so dp = min(those three) + 1. Track the largest side; the answer is its square.

maximal_square.py
from typing import List

class Solution:
    def maximalSquare(self, matrix):
        m, n = len(matrix), len(matrix[0])
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        best = 0
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if matrix[i - 1][j - 1] == "1":
                    # square capped by its top, left, and top-left neighbours
                    dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
                    best = max(best, dp[i][j])
        return best * best

Time O(m·n) · Space O(m·n). The 'min of three neighbours + 1' square recurrence is a distinctive, reusable pattern.

19 LC 1277Count Square Submatrices with All Ones Medium Same square DP · sum the sides

Problem. Count all square submatrices (of any size) that contain only 1s. LeetCode 1277 ↗

Clarify: Count squares of every size, at every position? (Yes.)

Hint 1
Use the same dp[i][j] = largest square side ending at (i,j).
Hint 2
That value also counts the squares ending there — sum them all.

How to think about it The same square-side DP as Maximal Square, with a neat twist: if the largest square ending at (i, j) has side k, then there are exactly k all-ones squares ending there (sides 1..k). So instead of tracking the maximum, sum every dp[i][j] to count all squares.

count_squares.py
from typing import List

class Solution:
    def countSquares(self, matrix):
        m, n = len(matrix), len(matrix[0])
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        total = 0
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if matrix[i - 1][j - 1] == 1:
                    dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
                    total += dp[i][j]   # each cell adds its largest square's count
        return total

Time O(m·n) · Space O(m·n). The same recurrence answers 'largest' or 'how many' depending on whether you max or sum.

20 LC 10Regular Expression Matching Hard Matching DP · '.' and '*'

Problem. Implement regex matching where '.' matches any single char and '*' matches zero or more of the preceding element, over the whole string. LeetCode 10 ↗

Clarify: '*' applies to the character before it? (Yes.) Match the entire string? (Yes.)

Hint 1
dp[i][j] = does s[:i] match p[:j]?
Hint 2
For '*': match zero of the prev char (dp[i][j−2]), or one more if the prev char matches s[i−1] (dp[i−1][j]).

How to think about it A two-string boolean grid. dp[i][j] asks whether s[:i] matches p[:j]. A plain char or . consumes one character diagonally. A * either takes zero of its preceding element (dp[i][j−2]) or, if that element matches s[i−1], extends a match by one (dp[i−1][j]). Seed the empty-string patterns carefully.

regex_matching.py
class Solution:
    def isMatch(self, s, p):
        m, n = len(s), len(p)
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True
        for j in range(1, n + 1):                    # patterns matching empty s
            if p[j - 1] == "*":
                dp[0][j] = dp[0][j - 2]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == "*":
                    dp[i][j] = dp[i][j - 2]           # '*' matches zero of prev char
                    if p[j - 2] == "." or p[j - 2] == s[i - 1]:
                        dp[i][j] = dp[i][j] or dp[i - 1][j]   # or one more
                elif p[j - 1] == "." or p[j - 1] == s[i - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
        return dp[m][n]

Time O(m·n) · Space O(m·n). The '*' transition (zero-or-more) is the crux — get its two branches right and the rest is standard grid DP.

21 LC 44Wildcard Matching Hard Matching DP · '?' and '*'

Problem. Implement wildcard matching where '?' matches any single char and '*' matches any sequence (including empty), over the whole string. LeetCode 44 ↗

Clarify: '*' matches any run including empty? (Yes.) Match the entire string? (Yes.)

Hint 1
dp[i][j] = does s[:i] match p[:j]?
Hint 2
For '*': match empty (dp[i][j−1]) or consume one char (dp[i−1][j]).

How to think about it Similar grid to regex but simpler, since * stands alone. dp[i][j] is whether s[:i] matches p[:j]. A * either matches an empty run (dp[i][j−1]) or absorbs one more character (dp[i−1][j]); ? or an exact char consumes one diagonally. Initialise leading *s to match the empty string.

wildcard_matching.py
class Solution:
    def isMatch(self, s, p):
        m, n = len(s), len(p)
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True
        for j in range(1, n + 1):
            if p[j - 1] == "*":
                dp[0][j] = dp[0][j - 1]               # '*' matches empty
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == "*":
                    dp[i][j] = dp[i - 1][j] or dp[i][j - 1]   # match a char / match empty
                elif p[j - 1] == "?" or p[j - 1] == s[i - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
        return dp[m][n]

Time O(m·n) · Space O(m·n). Compare with regex: here '*' is free-standing, so its two branches are 'skip star' vs 'consume a char'.

22 LC 115Distinct Subsequences Hard Two-string counting DP

Problem. Count the distinct subsequences of s that equal t. LeetCode 115 ↗

Clarify: Count how many ways t appears as a subsequence of s? (Yes.)

Hint 1
dp[i][j] = number of ways t[:j] appears in s[:i].
Hint 2
Always inherit dp[i−1][j] (skip s[i−1]); if chars match, add dp[i−1][j−1].

How to think about it Let dp[i][j] count how many times t[:j] appears as a subsequence of s[:i]. You can always ignore the current s character (dp[i−1][j]); if s[i−1] == t[j−1], you may also match it, adding dp[i−1][j−1]. An empty t matches once, so column 0 is all 1s.

distinct_subsequences.py
class Solution:
    def numDistinct(self, s, t):
        m, n = len(s), len(t)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):
            dp[i][0] = 1              # empty t is a subsequence once
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                dp[i][j] = dp[i - 1][j]               # skip s[i-1]
                if s[i - 1] == t[j - 1]:
                    dp[i][j] += dp[i - 1][j - 1]      # or match it
        return dp[m][n]

Time O(m·n) · Space O(m·n). A counting version of subsequence matching — 'skip, or skip-and-match' sums the ways.

23 LC 312Burst Balloons Hard Interval DP · pick the LAST burst

Problem. Bursting balloon i earns left×i×right (neighbours in the current row). Maximise total coins. LeetCode 312 ↗

Clarify: Coins depend on current adjacent balloons? (Yes.) Pad the ends with value-1 balloons? (Yes.)

Hint 1
Deciding the FIRST balloon to burst is hard because neighbours change; instead fix the LAST balloon in an interval.
Hint 2
dp[left][right] over the LAST balloon k: dp[left][k] + dp[k][right] + pad[left]*pad[k]*pad[right].

How to think about it The classic interval DP with a twist: decide the balloon burst last in an interval, not first. When k bursts last in the open interval (left, right), its neighbours are the padded boundaries left and right, giving pad[left]·pad[k]·pad[right] plus the two now-independent sub-intervals. Fill by increasing interval width.

burst_balloons.py
from typing import List

class Solution:
    def maxCoins(self, nums):
        balloons = [1] + nums + [1]   # padded boundaries
        n = len(balloons)
        dp = [[0] * n for _ in range(n)]
        for length in range(2, n):    # interval width
            for left in range(n - length):
                right = left + length
                for k in range(left + 1, right):      # k is the LAST balloon burst
                    dp[left][right] = max(
                        dp[left][right],
                        dp[left][k] + dp[k][right]
                        + balloons[left] * balloons[k] * balloons[right])
        return dp[0][n - 1]

Time O(n³) · Space O(n²). 'Fix the last action so subproblems become independent' is the signature interval-DP insight.

24 LC 664Strange Printer Hard Interval DP · merge equal ends

Problem. A printer prints one contiguous run of the same character per turn (over-printing existing chars). Return the fewest turns to print the string. LeetCode 664 ↗

Clarify: Each turn prints one run of a single character? (Yes.) Later prints overwrite earlier ones? (Yes.)

Hint 1
Collapse consecutive duplicates first — they never cost extra.
Hint 2
dp[i][j]: print s[j] alone (dp[i][j−1]+1), or if some s[k]==s[j], merge that print to save a turn.

How to think about it After collapsing runs, define dp[i][j] as the fewest turns to print s[i..j]. Baseline: print s[j] in its own turn (dp[i][j−1]+1). But if some earlier s[k] == s[j], that print can be extended to cover s[j] for free, splitting the interval at k. Take the minimum over all such k.

strange_printer.py
class Solution:
    def strangePrinter(self, s):
        # collapsing consecutive duplicates never changes the answer
        s = "".join(ch for i, ch in enumerate(s) if i == 0 or ch != s[i - 1])
        n = len(s)
        if n == 0:
            return 0
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = 1
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                dp[i][j] = dp[i][j - 1] + 1           # print s[j] on its own
                for k in range(i, j):
                    if s[k] == s[j]:                  # extend an earlier same-char print
                        right = dp[k + 1][j - 1] if k + 1 <= j - 1 else 0
                        dp[i][j] = min(dp[i][j], dp[i][k] + right)
        return dp[0][n - 1]

Time O(n³) · Space O(n²). Merging equal endpoints to save a turn is a recurring interval-DP move (see also Remove Boxes).

25 LC 87Scramble String Hard Interval recursion + memo

Problem. Determine whether s2 is a scramble of s1, where scrambling recursively swaps the two halves of substrings. LeetCode 87 ↗

Clarify: A scramble may recursively swap partitions at any split? (Yes.) Both strings equal length? (Yes.)

Hint 1
Prune: if the two substrings have different character multisets, they can't match.
Hint 2
For each split i: children match in order (a[:i]~b[:i]) OR swapped (a[:i]~b[n−i:]).

How to think about it Recurse on substring pairs with memoization. Two substrings scramble-match if they're equal, and can be pruned instantly when their sorted characters differ. Otherwise try every split point: the halves either match in the same order, or with the two halves swapped. Caching keeps the exponential branching in check.

scramble_string.py
from functools import lru_cache

class Solution:
    def isScramble(self, s1, s2):
        if len(s1) != len(s2):
            return False

        @lru_cache(None)
        def dp(a, b):
            if a == b:
                return True
            if sorted(a) != sorted(b):    # different multisets ⇒ never scrambles
                return False
            n = len(a)
            for i in range(1, n):
                # split with matching order, or with swapped halves
                if dp(a[:i], b[:i]) and dp(a[i:], b[i:]):
                    return True
                if dp(a[:i], b[n - i:]) and dp(a[i:], b[:n - i]):
                    return True
            return False

        return dp(s1, s2)

Time O(n⁴) · Space O(n³). Top-down memo shines when the interval structure has a swap/split branching that's awkward to tabulate.

26 LC 1039Minimum Score Triangulation of Polygon Hard Interval DP · pick the apex

Problem. Triangulate a convex polygon (values at vertices); a triangle scores the product of its three vertices. Minimise the total score. LeetCode 1039 ↗

Clarify: Triangulate into n−2 triangles? (Yes.) Minimise the sum of triangle products? (Yes.)

Hint 1
dp[i][j] = min score to triangulate the polygon from vertex i to j.
Hint 2
Pick an apex k between i and j: dp[i][k] + dp[k][j] + values[i]*values[k]*values[j].

How to think about it Interval DP over vertex ranges. dp[i][j] is the minimum score to triangulate the sub-polygon spanning vertices i..j. For the edge (i, j), choose the third vertex k of the triangle on that edge; that triangle costs values[i]·values[k]·values[j] and splits the polygon into two independent sub-polygons. Minimise over all k.

triangulation.py
from typing import List

class Solution:
    def minScoreTriangulation(self, values):
        n = len(values)
        dp = [[0] * n for _ in range(n)]
        for length in range(2, n):
            for i in range(n - length):
                j = i + length
                dp[i][j] = min(
                    dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]
                    for k in range(i + 1, j))
        return dp[0][n - 1]

Time O(n³) · Space O(n²). Same 'pick the pivot vertex, split into two intervals' engine as Burst Balloons and matrix-chain multiplication.

4 · Interview playbook

  • Name the two indices. "dp[i][j] = LCS of the first i and first j characters" — pin down what each axis means before writing the recurrence.
  • Match the shape: grid (from above/left), two-sequence (match ⇒ diagonal), palindrome/interval (ends + inner range), knapsack (item × capacity).
  • Fill order matters: grid DP row-major, interval DP by increasing length. Filling wrong reads uninitialised cells.
  • Use the 0-row/0-column for empty prefixes to kill off-by-one base cases.
  • Interval trick: fixing the last action (Burst Balloons) or merging equal endpoints (Strange Printer) makes subproblems independent.

6 · Review

Cheat sheet
  • Path through a matrix (count/min/max) → grid DP (from above + left).
  • Compare/align two sequences → two-sequence DP (match ⇒ diagonal, else neighbours).
  • Edit distance → insert/delete/replace = 1 + min of three neighbours.
  • Palindromic sub-things / substring feasibility → interval palindrome DP.
  • Subset with a target or two capacities → 2D knapsack (capacity downward for 0/1).
  • Largest / count squares in a binary matrix → min(top, left, top-left) + 1.
  • Range split at k, matching, matrix-chain → interval DP (fill by length; fix the last action).
  • Regex / wildcard → two-string boolean grid with special '*' branches.

Concept checks

In the LCS grid, why add an extra row and column of zeros (indices 0)?
They represent an empty prefix of each string, giving correct base cases so the match/mismatch recurrence works uniformly without special-casing i=0 or j=0 inside the loop
To make the table square
To leave room for the answer
dp[0][j] and dp[i][0] mean 'one string is empty', whose LCS is 0. Seeding those to zero lets every real cell reference dp[i−1][j−1], dp[i−1][j], dp[i][j−1] without bounds checks — the padding is the base case.
In Burst Balloons, why is it easier to fix the LAST balloon burst in an interval rather than the first?
If k is burst last in (left, right), its neighbours are exactly the fixed interval boundaries, so the two sub-intervals become independent; choosing the first balloon leaves changing, interdependent neighbours
Because the first balloon always earns the fewest coins
Because it lets you use a greedy instead of DP
The difficulty is that bursting changes neighbours. By declaring k the last burst in the open interval, everything else inside is already gone, so k's neighbours are the boundaries left and right — and the left and right sub-intervals no longer interact, giving a clean dp[left][k] + dp[k][right] + product split.
