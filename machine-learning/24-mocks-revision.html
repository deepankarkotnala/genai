1 · How to use this module

Every drill here is a performance rehearsal, not a reading exercise. The rapid-fire bank in section 5 is collapsed by default on purpose: read the question, say your answer aloud, then expand to check. Any miss sends you back to the module named in that entry.

2 · The five timed mock rounds

Round 1 — Theory (45 min)

Run these in sequence, timed, out loud.

  1. Walk me through logistic regression from first principles, including why we use log odds. (10 min)
  2. Derive log-loss from the Bernoulli likelihood, then its gradient. (8 min)
  3. Explain the bias–variance trade-off and give three hyperparameters that move along it. (5 min)
  4. Compare bagging and boosting across five dimensions. (7 min)
  5. What does XGBoost add over standard gradient boosting? (8 min)
  6. Why does L1 produce sparsity? Give both arguments. (7 min)

Round 2 — Applied case study (45 min)

🧭
The brief

A subscription business wants to reduce churn. They have 3 years of data, 800,000 customers, about 40 tables in a warehouse, monthly billing, and a retention team that can contact 5,000 customers per month. Build them a solution.

Work it in this order and time yourself:

  1. Clarify — what counts as churn: voluntary cancellation, payment failure, or inactivity? What does a save cost, and what is a saved customer worth? How far ahead do they need warning?
  2. Target definition — the hardest and most important part. The label and the horizon determine everything downstream.
  3. Leakage audit — the cancellation record and anything downstream of it must be excluded, and features must be as-of the prediction date.
  4. Split — time-based with a gap for label maturation, and grouped by customer.
  5. Baseline — a simple tenure-and-engagement rule.
  6. Model — gradient boosting, plus a logistic regression for interpretability.
  7. Metric — the retention team can contact 5,000 per month, so the metric is precision@5000, not F1 and not accuracy. This is the single most important insight in the case and interviewers watch for it.
  8. Ranking — rank and take the top 5,000 rather than thresholding at 0.5.
  9. Uplift caveat — a strong answer notes that churn probability is not the same as saveability, and that the ideal target is the incremental effect of contact, which requires an experiment (uplift modelling).
  10. Deployment — monthly batch scoring is sufficient; no real-time serving needed.
  11. Measurement — a randomized holdout among the top-ranked customers is the only way to know whether the intervention actually works.

3 · The one-page cheat sheet

On the day of the interview, read only this and the rejection-causes list below. Do not learn anything new.

cheat_sheet.txt
=== FORMULAS ===
Sigmoid  s(z)=1/(1+e^-z) ;  s' = s(1-s) ;  logit(p)=log(p/(1-p))
Log-loss  -SUM[y log p + (1-y)log(1-p)]      grad = X'(p - y)
OLS       w=(X'X)^-1 X'y                     Ridge w=(X'X + lam*I)^-1 X'y
Gini      1 - SUM p²        Entropy  -SUM p log2 p
Bias-var  E[err] = bias² + variance + noise
Bagging   Var = rho*sig² + (1-rho)*sig²/B     <- RF reduces rho
XGB leaf  w* = -G/(H+lam)
XGB gain  0.5*[G_L²/(H_L+lam) + G_R²/(H_R+lam) - G²/(H+lam)] - gamma
Precision TP/(TP+FP)   Recall TP/(TP+FN)   F1 = 2PR/(P+R)
Threshold t* = C_FP/(C_FP + C_FN)
Bootstrap ~63.2% in-bag, ~36.8% out-of-bag

=== ONE-LINERS ===
Why log odds?    Unbounded predictor vs bounded p; canonical Bernoulli link;
                 convex loss; grad X'(p-y); odds ratios e^w
Why not MSE?     Non-convex with sigmoid + vanishing gradient from s'
Bagging          parallel, deep learners, cuts VARIANCE, will not overfit with more trees
Boosting         sequential, weak learners, cuts BIAS, WILL overfit, early stop
RF adds          feature subsampling -> decorrelation -> lowers the rho*sig² floor
GBM tree fits    negative gradient of loss wrt predictions (= residual only for MSE)
XGBoost adds     2nd-order Taylor + regularized objective + sparsity-aware splits
Need scaling     KNN, K-Means, SVM, PCA, regularized linear, NNs.  NOT trees.
Imbalance order  metric -> threshold -> class weight -> resample (in-fold!) -> reframe
ROC vs PR        PR when positives are rare; FPR's huge denominator hides FP growth
L1 sparsity      diamond corners + constant lam*sign subgradient -> soft threshold
Leakage types    target, preprocessing, temporal, group, duplicate, selection
Drift            data=P(x) detectable now; concept=P(y|x) needs labels; label=P(y)
SHAP             local + additive + consistent - but NOT causal

⚠️
The 12 things that get candidates rejected
  1. Cannot explain why log odds beyond “because sigmoid”.
  2. Confuses precision and recall, or cannot pick between them for a stated business cost.
  3. Reports accuracy on an imbalanced problem without flagging it.
  4. Scales or imputes before splitting, leaking test information into training.
  5. Cannot explain the bias–variance consequence of a hyperparameter they just named.
  6. Says “Random Forest is boosting”, or otherwise mixes up bagging and boosting.
  7. Cannot state what gradient boosting fits each tree to.
  8. Uses random K-fold on time-series data.
  9. Treats feature importance as causal.
  10. Cannot name a single thing that breaks after deployment.
  11. Gives a memorized answer that does not match the asked question — the most common failure in 2026 loops, because rehearsed answers are easy to spot.
  12. Never asks a clarifying question in an applied or design round.

5 · Rapid-fire bank — 60 questions

60 questions
01Difference between classification and regression?basics＋
Strong answer

The target’s measurement scale — and then loss, link function, metric and error meaning all follow from it. Uniquely, classification also needs a threshold the model never supplies.

Revise in: Module 03
02Why log odds and not probability directly?log odds＋
Strong answer

A linear predictor is unbounded but a probability is not, so model the log-odds linearly and invert — which produces the sigmoid. It is also Bernoulli’s canonical link, giving convexity, a clean gradient and odds ratios.

Revise in: Module 07
03Why not MSE for logistic regression? Two reasons.loss＋
Strong answer

Sigmoid-plus-MSE is non-convex, so you can hit local minima; and its gradient carries a σ' factor that vanishes exactly when the model is confidently wrong. Log-loss is convex and cancels σ'.

Revise in: Module 07
04Define precision and recall.metrics＋
Strong answer

Precision = TP/(TP+FP), down the predicted-positive column — can I trust my alerts. Recall = TP/(TP+FN), across the actual-positive row — am I missing cases.

Revise in: Module 10
05Bias–variance decomposition — the three terms?fundamentals＋
Strong answer

bias² + variance + irreducible noise, with the expectation taken over training sets.

Revise in: Module 05
06Why does L1 give exact zeros?regularization＋
Strong answer

Geometrically its diamond has corners on the axes; mechanically its subgradient is a constant λ·sign(w) that never fades as w → 0, whereas L2’s 2λw does.

Revise in: Module 08
07What does each gradient-boosting tree fit?boosting＋
Strong answer

The negative gradient of the loss with respect to current predictions. That equals the residual only under squared error.

Revise in: Module 17
08Bagging vs boosting — one sentence each.ensembles＋
Strong answer

Bagging: parallel, deep learners on bootstrap samples, cuts variance, plateaus. Boosting: sequential, weak learners on the current errors, cuts bias, will overfit.

Revise in: Module 16
09Random Forest = bagging + what?ensembles＋
Strong answer

Random feature subsampling at every split, which decorrelates the trees and so lowers the ρσ² variance floor.

Revise in: Module 16
10Can more trees overfit a Random Forest? Boosting?ensembles＋
Strong answer

RF: no — independent trees, averaged, so error plateaus. Boosting: yes — each tree fits current residuals, so early stopping is mandatory.

Revise in: Module 16
11Which algorithms need feature scaling?preprocessing＋
Strong answer

Anything using distances, dot products or a loss surface: KNN, K-Means, SVM, PCA, regularized linear models, neural nets. Not trees.

Revise in: Module 02
12Why don’t trees need scaling?trees＋
Strong answer

A split only needs the ranking of one feature’s values, which any monotone transform preserves. Trees never combine features into a single quantity.

Revise in: Module 15
13Gini vs entropy — which is better?trees＋
Strong answer

Practically neither; they pick the same split almost always. Gini avoids a logarithm so it is marginally faster and is the default. Not worth tuning.

Revise in: Module 15
14What is a support vector?SVM＋
Strong answer

A point on or violating the margin — one with a non-zero dual coefficient. Delete every other training point and the hyperplane is unchanged.

Revise in: Module 14
15Explain the kernel trick.SVM＋
Strong answer

The dual depends on the data only through inner products, so a kernel computes φ(xᵢ)·φ(xⱼ) directly from the original inputs — you never construct φ.

Revise in: Module 14
16Does larger C mean more or less regularization?sklearntrap＋
Strong answer

Less. C = 1/λ, so small C means strong regularization. Note Ridge/Lasso use alpha, where bigger means more.

Revise in: Modules 07, 14
17When is ROC-AUC misleading?metrics＋
Strong answer

When positives are rare. FPR’s huge negative denominator hides false-positive growth that collapses precision.

Revise in: Module 10
18PR-AUC baseline value?metrics＋
Strong answer

The positive class rate — not 0.5. So a PR-AUC of 0.3 on a 1%-positive problem is 30× baseline.

Revise in: Module 10
19Why is F1 a harmonic mean?metrics＋
Strong answer

Because the harmonic mean is dominated by the smaller value, so you cannot game it by collapsing precision or recall.

Revise in: Module 10
20How do you choose a decision threshold?threshold＋
Strong answer

From business cost on validation data — minimize FP·C_FP + FN·C_FN — or from an operational constraint like reviewable alert volume. Never leave it at 0.5.

Revise in: Module 10
21Optimal threshold formula from costs?threshold＋
Strong answer

t* = C_FP/(C_FP + C_FN) for a calibrated model. So a 10-versus-190 cost ratio gives 0.05.

Revise in: Module 10
22Name five kinds of data leakage.leakage＋
Strong answer

Target, preprocessing contamination, temporal, group, and duplicate — plus selection or tuning performed on the full dataset.

Revise in: Module 04
23Where does resampling belong in a pipeline?imbalancetrap＋
Strong answer

Inside the pipeline, training fold only — via imblearn’s Pipeline, not sklearn’s. Otherwise synthetic points derived from test rows leak in.

Revise in: Module 12
24Downsides of SMOTE?imbalance＋
Strong answer

Invalid for categoricals, amplifies label noise, degrades in high dimensions, blurs the boundary, breaks calibration — and leaks badly if applied before splitting.

Revise in: Module 12
25Is class imbalance always a problem?imbalance＋
Strong answer

No. What matters is the absolute positive count plus an appropriate metric and threshold — not the ratio.

Revise in: Module 12
26RMSE vs MAE — which statistic does each predict?metrics＋
Strong answer

MSE targets the conditional mean; MAE targets the conditional median. On skewed targets those differ substantially.

Revise in: Module 11
27Can R² be negative?metrics＋
Strong answer

Out-of-sample yes — it means you are worse than predicting the training mean. In-sample it stays in [0,1] and cannot fall when you add features.

Revise in: Module 06
28Assumptions of linear regression?linear＋
Strong answer

Linearity in parameters, exogeneity, homoscedasticity, no autocorrelation, no perfect collinearity — plus normality of errors for small-sample inference only.

Revise in: Module 06
29Is normality required for OLS to be BLUE?lineartrap＋
Strong answer

No. Gauss–Markov needs linearity, zero-mean errors, homoscedasticity and no autocorrelation. Normality only buys exact t and F distributions.

Revise in: Module 06
30What does multicollinearity break?linear＋
Strong answer

Coefficient interpretation — estimates become unstable and standard errors inflate. Predictions are usually fine.

Revise in: Module 06
31When is XᵀX not invertible, and what then?linear＋
Strong answer

Perfectly collinear features, or d > n. Use the pseudo-inverse via SVD, or ridge — (XᵀX + λI) is always invertible for λ > 0.

Revise in: Module 06
32Normal equation vs gradient descent — when each?optimization＋
Strong answer

Normal equation for small-to-moderate d; gradient descent when d is large (the d³ inversion dominates), n exceeds memory, or the loss has no closed form.

Revise in: Modules 06, 09
33Batch vs SGD vs mini-batch?optimization＋
Strong answer

Batch is exact but O(nd) per step; SGD is O(d) but noisy and needs a decaying rate; mini-batch balances gradient variance against speed and suits vectorized hardware.

Revise in: Module 09
34What does AdamW decouple?optimization＋
Strong answer

Weight decay from the gradient. In Adam an L2 term also gets divided by √v̂, so it is not true weight decay; AdamW applies it directly to the weights.

Revise in: Module 09
35Gradient boosting vs gradient descent?boosting＋
Strong answer

The same algorithm in function space rather than parameter space: the tree approximates the negative functional gradient, and shrinkage is the step size.

Revise in: Modules 09, 17
36Does gradient descent find the global minimum?optimization＋
Strong answer

Only for convex objectives — true for linear and logistic regression, not neural nets. And in high dimensions the real obstacle is saddle points, not local minima.

Revise in: Module 09
37Why does scaling speed up gradient descent?optimization＋
Strong answer

It improves the loss surface’s condition number, so the gradient points at the optimum instead of zig-zagging across an elongated canyon.

Revise in: Module 09
38XGBoost’s key addition over standard GBM?XGBoost＋
Strong answer

A regularized objective plus a second-order Taylor expansion using gradient and Hessian, giving closed-form leaf weights — Newton’s method in function space.

Revise in: Module 18
39XGBoost optimal leaf weight formula?XGBoost＋
Strong answer

w* = −G/(H + λ), with the leaf’s optimal contribution −½G²/(H + λ).

Revise in: Module 18
40How does XGBoost handle missing values?XGBoost＋
Strong answer

It learns a default direction per split — trying all-missing-left and all-missing-right, keeping whichever gives higher gain.

Revise in: Module 18
41What is min_child_weight thresholding?XGBoosttrap＋
Strong answer

The sum of Hessians in a leaf — confidence-weighted information, not the raw row count.

Revise in: Module 18
42LightGBM: what is leaf-wise growth?LightGBM＋
Strong answer

Always splitting the highest-gain leaf anywhere in the tree, rather than level by level. Lower loss per leaf, but deep unbalanced trees that overfit small data.

Revise in: Module 18
43What do GOSS and EFB do?LightGBM＋
Strong answer

GOSS keeps all large-gradient rows and subsamples small-gradient ones; EFB bundles mutually-exclusive sparse features. Together they are why LightGBM is fast.

Revise in: Module 18
44What does CatBoost’s ordered boosting solve?CatBoost＋
Strong answer

Prediction shift — the target leakage from computing a sample’s residual with a model trained on that sample. Residuals use only preceding rows in a permutation.

Revise in: Module 18
45Curse of dimensionality — two consequences?geometry＋
Strong answer

Distances concentrate, so nearest and farthest neighbours converge; and nearly all volume sits near the surface, so every point is on the boundary.

Revise in: Module 13
46How does k in KNN affect bias/variance?KNN＋
Strong answer

Small k means low bias and high variance with a jagged boundary; large k smooths, adding bias and cutting variance. Increasing k regularizes.

Revise in: Module 13
47Why does Naive Bayes work despite false assumptions?Naive Bayes＋
Strong answer

Classification needs only the argmax to be right. Independence distorts probability magnitudes but usually preserves class ranking — a good classifier, a bad probability estimator.

Revise in: Module 13
48What is Laplace smoothing for?Naive Bayes＋
Strong answer

Preventing a single unseen feature value from zeroing the whole product. It is equivalent to a Dirichlet prior with a MAP estimate.

Revise in: Module 13
49LDA vs PCA?dim. reduction＋
Strong answer

PCA is unsupervised maximum variance; LDA is supervised maximum class separation, capped at K−1 components.

Revise in: Modules 13, 19
50K-Means assumptions?clustering＋
Strong answer

Spherical, similar-size, similar-density clusters with k known — plus scaled features, and it is outlier-sensitive because centroids are means.

Revise in: Module 19
51Why are PCA components orthogonal?PCA＋
Strong answer

The covariance matrix is real and symmetric, and the spectral theorem guarantees a symmetric matrix has an orthogonal eigenbasis.

Revise in: Module 19
52Should you always apply PCA first?PCAtrap＋
Strong answer

No. It is unsupervised, so the top-variance direction can be one where classes are completely mixed — and it destroys the axis-aligned structure trees rely on.

Revise in: Module 19
53What can’t you conclude from a t-SNE plot?visualizationtrap＋
Strong answer

Anything from the between-cluster distances or the apparent cluster sizes. Only local neighbourhood structure is preserved.

Revise in: Module 19
54Why is random search better than grid search?tuning＋
Strong answer

Parameter importance is uneven, so a grid burns m^d fits re-testing irrelevant parameters. Random search samples N distinct values per parameter.

Revise in: Module 20
55Can hyperparameter tuning overfit?tuning＋
Strong answer

Yes — taking the maximum over many noisy CV estimates is upward-biased, so the winning score is not an unbiased estimate.

Revise in: Module 20
56What is nested cross-validation for?validation＋
Strong answer

An unbiased estimate of the whole procedure including hyperparameter selection: an inner loop tunes, an outer loop scores.

Revise in: Modules 05, 20
57Data drift vs concept drift?production＋
Strong answer

Data drift is P(x) moving, detectable immediately from inputs. Concept drift is P(y|x) moving and needs labels, so only detectable after your label delay.

Revise in: Module 22
58What is training/serving skew?production＋
Strong answer

Serving features differing from training features — two code paths, different defaults, units, timezones or category vocabularies. Fix with one serialized pipeline or a feature store.

Revise in: Module 22
59Is SHAP causal?SHAPtrap＋
Strong answer

No. It explains what the model used, not what causes the outcome. Acting on it as causal is the defining error of interpretability work.

Revise in: Module 21
60Logistic regression vs a neural network?bridge＋
Strong answer

Logistic regression is a neural network with no hidden layers. Depth adds learned representations; the output layer is still logistic or softmax regression.
